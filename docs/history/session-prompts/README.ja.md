# 歴史的 session resume prompt

長期実行開発中にメンテナが使用した session ごと resume prompt の
歴史的アーカイブ。特定過去時点のプロジェクト状態を記述しており、
**onboarding 資料として意図されていない** — 新規 contributor は
[docs root](../../index.ja.md) と
[`docs/getting-started/`](../../getting-started/) から始めるべき。

各ファイルは snapshot: ここで記述される open PR 名、in-flight
作業、open Issue は現在の状態とほぼ確実に一致しない。`git log` と
live GitHub Issue tracker で現在ビューを取得すること。

ファイルは 2026-08-07 に repo-hygiene シリーズ (PR D of A-G) の
一環として `docs/session-*.md` から relocate された。ドット prefix
の作業ファイル `.session-resume-prompt.md` は repo root に留まり
(gitignored)、これは別メカニズム。
