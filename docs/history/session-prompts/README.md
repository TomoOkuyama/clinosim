# Historical session resume prompts

Historical archive of per-session resume prompts used by the maintainer during
long-running development. These describe project state at specific past points
and are **not intended as onboarding material** — new contributors should start
with [the docs root](../../index.md) and [`docs/getting-started/`](../../getting-started/).

Each file is a snapshot: names of open PRs, in-flight work, and open Issues
described here almost certainly no longer match the current state. Use `git log`
and the live GitHub Issue tracker for the current view.

Files were relocated from `docs/session-*.md` on 2026-08-07 as part of the
repo-hygiene series (PR D of A-G). The dot-prefixed working file
`.session-resume-prompt.md` remains at the repo root (gitignored) and is a
separate mechanism.
