# docs/superpowers/

In-flight brainstorming / spec / plan files for active workstreams. Files
here are working documents that get referenced during ongoing PRs.

Once a workstream ships (PR merged, Issue closed), its spec and plan
files move to `docs/history/{specs,plans}-archive/` to keep this folder
signal-heavy.

## Layout expectations

- Empty most of the time — active work only.
- Filename convention: `YYYY-MM-DD-<issue-or-topic>-{design,plan}.md`.
- Completed files: moved to `../history/{specs,plans}-archive/`.
